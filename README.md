# slm-doc-extract-bench
Local-first benchmark comparing multimodal SLMs (Qwen2.5/3-VL, InternVL3, SmolVLM2) vs OCR+text SLM pipelines (Tesseract/PaddleOCR + Phi-4-mini, Gemma3, Llama 3.2) for document extraction. Runs fully offline via Ollama/transformers. Field-level F1, latency, JSON-validity metrics + auto leaderboard.
